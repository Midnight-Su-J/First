# 🧩 JigsawGame - Java 拼图游戏

基于Java Swing开发的桌面拼图游戏。

---

## 功能特性

### 用户系统
- 登录 — 校验用户名+密码，错误提示（密码错/用户不存在）
- 注册 — 两次密码确认、用户名重复检测，注册成功后自动返回登录页
- 默认内置账号：“Midnight_Su”/ “123456”

### 拼图游戏
- 4 × 4拼图玩法，支持方向键（↑ ↓ ← →）移动空白块
- 两套图片可切换（ACG01/ACG02）
- 实时显示步数统计
- 按住A键预览完整原图，松开恢复拼图
- 按住W键直接胜利
- 胜利后显示通关图片

---

## 操作说明

| 操作      | 按键      | 说明                  |
|-----------|----------|-----------------------|
| 移动空白块 | ↑ ↓ ← →  | 比如空白块要向右，就按 →|
| 预览完整图 | 按住A    | 松开恢复拼图            |
| 一键胜利   | 松开W    | 用于测试或不想玩了      |    
    
### 菜单栏

| 菜单 | 选项     | 功能               |
|------|---------|--------------------|
| 功能 | 更换图片 | 切换拼图素材        |
| 功能 | 重新游戏 | 打乱当前图片重新开始 |
| 功能 | 重新登录 | 回到登录界面换账号   |
| 功能 | 退出游戏 | 关闭程序            |
| 关于 | 联系     | 显示作者Gitee       |
