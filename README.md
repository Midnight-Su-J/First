# 🧩 JigsawGame - Java 拼图游戏

基于Java Swing开发的桌面拼图游戏。

---

## 功能特性

### 用户系统
- 登录 — 校验用户名+密码，错误提示（密码错/用户不存在）
- 注册 — 两次密码确认、用户名重复检测，注册成功后自动返回登录页
- 默认内置账号：“Midnight_Su”/ “123456”

### 拼图游戏
- 4 × 4拼图玩法，支持方向键（↑ ↓ ← →）移动空白块
- 两套图片可切换（ACG01/ACG02）
- 实时显示步数统计
- 按住A键预览完整原图，松开恢复拼图
- 按住W键直接胜利
- 胜利后显示通关图片

# 🎬 本地Web播放器 - ArtPlayer

在浏览器里播放本机任意文件夹中的视频。Python标准库零框架后端 + ArtPlayer单页前端，无需安装、无需构建，启动即用。

## 功能特性

- **本机文件夹浏览与切换**：网页内选择盘符/进入子目录/返回上级，一键把任意文件夹设为当前视频目录。
- **选择视频文件**：在同一个浏览器弹窗里可直接点击某个视频文件，视频列表会同步切换到该文件所在文件夹并立即开始播放。
- **视频列表 + 自动封面**：ffmpeg 截取视频真实画面作为封面（优先第 3 秒，避开开头黑屏）。封面**只存在服务端内存中（LRU 2000 张），不在任何文件夹里写缓存文件**，重启服务后自动重新生成。
- **模糊搜索**：忽略英文大小写；关键词字符按顺序出现即可命中，允许少字；空格分隔的多个关键词需依次命中。
- **HTTP Range 拖动播放**：支持206分段请求，进度条可任意拖动，大文件无需整段下载。
- **ffmpeg无损转封装**：浏览器无法直接播放的封装（mkv/ts/flv/avi等）可在网页上上传，服务端转封装为 MP4：
  - 视频流H.264 时`-c:v copy`无损保留；音频为AAC/MP3时无损保留，其余编码转AAC 192k；
  - 加`+faststart`，支持网页边下边播；
  - 成品输出到**当前视频文件夹**：原名是`.mp4`则同名替换，其余扩展名输出为`同名.mp4`；
  - 临时文件直接建在目标文件夹内（同盘改名），规避跨盘移动导致的`WinError 5`。
- **播放器能力**（基于ArtPlayer 5.4.0）：画中画、截图、循环、全屏/网页全屏、自定义分组倍速菜单（一般倍速 0.25x–3x、其他倍速 3.25x–8x，两组互斥勾选）。
- **个性化背景**：内置4张背景图（2233/白金/白黑/warma），支持本地自定义图片，另有第三屏背景图浏览模式。

## 快速开始

### 1. 环境要求

- Windows + Python 3.8+（仅使用标准库，无需 pip 安装任何 Web 框架）
- **ffmpeg**（封面截帧与转封装需要）：
  - 方式一：把ffmpeg加入系统`PATH`（命令行输入`ffmpeg -version`能识别即可）；
  - 方式二：在Python环境中安装`pip install imageio-ffmpeg`，服务端会自动找到其自带的 ffmpeg。
  - 没有ffmpeg时播放器本身仍可正常使用，仅封面和转封装不可用。

### 2. 启动服务

在项目文件夹中打开命令行（在资源管理器地址栏输入`cmd`回车），执行：

```bat
python server.py
```

看到监听提示后，浏览器访问：

```
http://localhost:8000
```

### 3. 基本使用

1. 点击**选择文件夹**，在弹窗里选一个视频目录并点"使用此文件夹"（也可以直接点**选择视频文件**，在弹窗中点具体视频）；
2. 下方视频列表自动加载封面，点击任意封面即可播放；
3. 搜索框输入关键词可即时模糊过滤；
4. 遇到浏览器放不了的视频，点**ffmpeg 封装**选择本地文件，完成后自动生成MP4到当前视频文件夹。

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET |`/`| 前端页面 |
| GET |`/api/videos`| 返回 `{path, items:[{name, thumb}]}`，并在后台线程预生成缺失封面 |
| GET |`/api/browse?path=`| 列出指定目录下的子文件夹与视频文件；`path` 为空时列出盘符 |
| POST |`/api/set-root`| JSON body `{"path": "..."}`，切换当前媒体目录 |
| POST |`/api/remux`| 上传视频转封装；文件名经请求头 `X-Filename`（百分号编码）传递，body 为文件原始字节，流式落盘 |
| GET |`/.thumbnails/<目录哈希>/<文件名哈希>.jpg`| 封面图，命中内存缓存直接返回 |
| GET |`/<视频文件名>`| 媒体文件，支持`Range`请求（206） |

## 实现细节

- **两级静态资源解析**：页面、JS、背景图等内置资源始终从程序目录提供；视频等用户媒体从当前媒体目录提供。切换媒体目录后页面资源不受影响。
- **多线程服务**：`ThreadingHTTPServer`，每个请求独立线程；封面生成、ffmpeg 调用均不阻塞其他请求。
- **封面纯内存缓存**：`OrderedDict` 实现 LRU（上限 `THUMB_MEM_MAX = 2000`，约占 40~100MB），key 为目录 "MD5 + 文件名 MD5"，URL 不暴露真实路径；截帧临时文件建在系统临时目录并立即删除。重新封装同名视频后会主动作废旧封面。
- **ffmpeg 子进程加固**：`stdin=DEVNULL`、`close_fds=True`、Windows 下`CREATE_NO_WINDOW`，避免句柄继承导致挂起和弹窗；输出临时文件后缀为`.mp4.tmp`并显式指定`-f mp4`。
- **目录穿越防护**：对请求路径做`normpath`校验，拒绝逃逸出资源根目录的请求。

## 常见问题

**Q：mkv 等文件为什么还是放不了？**
浏览器只能解码特定编码。本项目转封装要求源视频为**H.264**才能无损处理；HEVC/H.265、AV1等Chromium不支持的编码需要真正重新编码（会显著降低画质、耗时很长），不在本工具范围内。

**Q：转封装卡住不动？**
若服务是在受限沙箱/某些IDE内置终端中启动的，向其他盘写入可能被系统拦截。请直接在普通`cmd`窗口里执行`python server.py` 启动。

**Q：控制台出现`net::ERR_ABORTED`？**
切换视频或切换文件夹时，浏览器会主动中止上一个视频尚未完成的请求，属于正常现象；服务端对缺失文件也已保证返回标准404而不是断开连接。

**Q：8000端口被占用？**
先关闭旧的服务窗口，或在[server.py](server.py) 中修改`PORT`后重启；修改代码后必须重启服务才会生效。

## 安全提示

[server.py](server.py) 中`HOST`默认为`0.0.0.0`。本服务可以浏览和切换本机目录、向媒体文件夹写入文件，**不建议直接暴露到局域网或公网**；仅本机使用时建议改为`HOST = "127.0.0.1"`。

# 🎡 Chouqian - java 随机抽签小程序

基于Java Swing的随机抽签小程序，支持姓名+照片同步滚动、权重抽取机制和可选的作弊设置。

## 功能特性

- **随机抽签**：点击「抽签」后姓名和照片同步快速滚动，再点一次「停止」确认抽中结果。
- **照片展示**：所有人配有头像，滚动时与姓名一同变动；图片采用 cover 居中裁剪，统一显示为正方形，不变形、不留白边。
- **权重机制**：每次被抽中后，该人下次被抽中的概率减半，实现"尽量不重复"的效果。
- **自动名单**：程序启动时自动扫描图片文件夹，以图片前缀名作为姓名生成`list.csv`，增删人员只需增删图片。
- **作弊设置**（可选）：
  - 第一排：填写"不会被抽到"的名字，这些人参与滚动但永远不会成为最终结果。
  - 第二排：填写"第 N 次必被抽中"的名字和次数，保证指定人恰好在第N次被抽中。

## 项目结构

```
Chouqian/
├── src/main/java/
│   ├── app.java          # 程序入口，启动时生成名单并打开开始界面
│   ├── Starter.java      # 开始界面
│   ├── Cheat.java        # 作弊设置窗口
│   └── Choice.java       # 抽签窗口（滚动、权重、作弊判定）
├── src/main/resources/Image/
│   ├── list/             # 人员照片文件夹（图片前缀名即姓名）
│   ├── icon.jpg          # 窗口图标
│   └── background.jpg    # 界面背景图
└── list.csv              # 抽签名单（启动时自动生成，格式：姓名,图片地址）
```

## 运行方式

直接运行 [app.java](src/main/java/app.java) 即可，流程为：

1. **开始界面** → 点击「开始」
2. **作弊设置**（可留空） → 点击「确定」
3. **抽签界面** → 点击「抽签」开始滚动，再点击「停止」确认结果

## 如何增删人员

将照片放入 `src/main/resources/Image/list/` 文件夹，**文件名前缀即为姓名**（例如 `张三.png` → 姓名"张三"）。支持 `.jpg`、`.jpeg`、`.png`、`.gif` 格式。程序下次启动时自动重新生成 `list.csv`，无需手动编辑。
